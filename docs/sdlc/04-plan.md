# 04 · Plan — modo contador web (Pyodide, todo local)

## Summary
- **3 iteraciones, 14 tareas, ≈ 15 h.** It. 1 (≈ 6 h) = núcleo compartido + página mínima que corre en Chrome con la CSP real → **demo: el contador abre la URL borrador y saca el Excel de sept.** (meta práctica de STATE). It. 2 (≈ 5 h) = extracto, cierre de seguridad, contrato v1, deploy prod por tag. It. 3 (≈ 3 h, Should) = avance, memoria del extracto, pulido.
- Orden backend-up: `libro.py` + tests (núcleo) → validación/topes + tests de ataque → Worker → página. Fitness de ADR-026/027/028 y CSP entran en It. 1.
- Riesgo 1 (CSP/Worker en Chrome) se ataca en T1, antes de construir la página; si falla, se anota en ADR-028 y se decide antes de seguir.
- Datos de prueba: crudo/extracto **sintéticos** en `web/pruebas/datos/` (el repo es público); el crudo real de sept. solo en el PC (`datos/`, ignorado).
